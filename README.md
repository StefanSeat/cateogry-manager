# Account Development Toolkit

Application project for the Account Development Analyst role (Clinical Research Group, PPD / Thermo Fisher Scientific). Static site: HTML, CSS and plain JavaScript, no build step. Hosted on GitHub Pages.

## Tabs

- **Lead Desk**: lead scoring (fit, pipeline and funding, intent, engagement) with adjustable weights, grades, SLA flags, next best action, auto-generated hand-off note and CSV export.
- **Funnel Analytics**: lead to RFP funnel, SQL conversion by source, weekly lead trend, computed insights and a copy-ready weekly report.
- **Playbook**: lead stages and exit criteria, SLAs, CRM hygiene rules, prospect research checklist, new hire onboarding plan, outreach templates.
- **Interview Prep**: job description mapping, company and CRO basics, likely questions, STAR stories, 30/60/90 plan, questions to ask.

All leads and companies are fictional and generated with a fixed seed in `js/data.js`.

Live site: https://stefanseat.github.io/interview/
