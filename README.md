# Eurospin Category Manager Prep

Interview preparation page for the Category Manager role at Eurospin Serbia (pre-launch). Italy and Croatia are used as reference markets. Static site (one `index.html`), hosted on GitHub Pages.

Sections: company overview, the role, category management process, KPIs and formulas, likely questions with answer outlines, 30/60/90 day plan, questions to ask, an Italy vs Croatia analysis, a flyer price comparison, and what is different about the Serbian launch.

Live site: https://stefanseat.github.io/cateogry-manager/
